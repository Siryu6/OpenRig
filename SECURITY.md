# Security policy

## Supported versions

Only the latest release gets security fixes. The OS image installs them as a
signed update (Settings → Updates).

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/Siryu6/OpenRig/security/advisories/new),
or by email to contact@openrig.eu.

Say what is affected (app, OS image, update signing, TONE3000 Connect…), the
version, and how to reproduce it. You will get an answer within a week. Once a
fix is released, the advisory is published and you are credited, unless you
prefer not to be.
