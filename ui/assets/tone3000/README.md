# TONE3000 logos

`tone3000-logo.svg` (full logo) and `t3k-mark.svg` (compact mark) are the
official assets of the TONE3000 logo package
(<https://www.tone3000.com/TONE3000%20Logos.zip>), used unmodified as the
TONE3000 API design requirements ask: the full logo at the entry points and
list headers, the mark in compact places.

They are trademarks of TONE3000 and are **not** covered by this project's
GPL-3.0 license. Do not use them outside the TONE3000 integration.
